# SmartLib Vue 可视化界面

## 启动

```powershell
cd "D:\Downloads\db project\09_SmartLib展示交付包\frontend_vue"
.\start_vue_dev.bat
```

打开 http://127.0.0.1:5173。

## 页面

- 数据大屏
- 高阶挖掘
- 智能问答
- 模型配置

## 配置

默认数据服务地址为 `http://127.0.0.1:8000`。如需修改，请编辑 `.env`：

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```
